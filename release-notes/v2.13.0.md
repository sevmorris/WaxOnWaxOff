**Changed**
- **The bundled FFmpeg is 9.0.2**, the newest line, up from 8.0.3, with **LAME 4.0**, up from 3.100. FFmpeg's 8.0 line has had no release since June, while 8.1 and 9.0 have had theirs in September, so the pin moves to the maintained newest line. WAV, FLAC, AIFF, CAF and MP3 sources process bit-identically to 2.12.5. AAC sources in MP4, MOV and M4A decode 59 samples (1.3 ms) shorter, because FFmpeg 9.0 accounts for the stream's padding differently; their loudness and true peak are unchanged. MP3 exports made with LAME 4.0 decode to exactly the same audio as with 3.100; only the encoder tag inside the file changes. (214 of 221 parity checks pass; the rest are those AAC timing differences.) The source verified against FFmpeg's release signing key, the licence files are unchanged, and the build is still this project's own reproducible, LGPL, audio-only recipe, now revision r5 (`ffmpeg-deps-9.0.2-audio-arm64-r5`).
