**Changed**
- **The bundled FFmpeg is 9.0.2**, the newest line, up from 8.0.3, with **LAME 4.0**, up from 3.100. FFmpeg's 8.0 line has had no release since June, while 8.1 and 9.0 have had theirs in September, so the pin moves to the maintained newest line. WAV, FLAC, AIFF, CAF and MP3 sources process bit-identically to 2.12.5, and so did a 70-minute phone recording in M4A. The exception is AAC that FFmpeg itself wrote: 9.0 now reads the encoder delay such files record, so they decode 59 samples (1.3 ms) shorter, with loudness and true peak unchanged. MP3 exports under LAME 4.0 differ very slightly from 3.100's: decoded, the difference peaks at −66 to −72 dBFS on real recordings, far below the codec's own noise, and loudness and true peak are identical. (214 of 221 parity checks pass; the rest are the timing differences of FFmpeg-written AAC.) The source verified against FFmpeg's release signing key, the licence files are unchanged, and the build is still this project's own reproducible, LGPL, audio-only recipe, now revision r5 (`ffmpeg-deps-9.0.2-audio-arm64-r5`).
