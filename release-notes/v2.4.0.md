### Bundled FFmpeg replaced — output verified bit-identical at identical settings

WaxOn/WaxOff now ships an **audio-only build of FFmpeg 8.0**, produced from a recipe committed to this repository (`scripts/build-ffmpeg.sh`), replacing the third-party GPL binary used through v2.3.0.

Parity was checked over a 17-fixture corpus before the swap: every WaxOn and WaxOff output matched the previous binary **byte for byte** at identical settings. Nothing about how your audio is processed has changed.

- **~44 MB combined, down from ~103 MB.** The video and image encoders are gone; nothing in either mode used them.
- **Build reproducibility.** The recipe compiles with `-ffp-contract=off`, so the output depends on the source rather than on which compiler version built it.
- **Won't ship a broken binary.** `--disable-autodetect` plus a hard `otool -L` check. An earlier attempt silently linked a Homebrew library and failed to launch on machines without it.

### Documentation

A full claim-by-claim audit of the manual, theory doc, in-app Help, and README against the implementation — **31 findings**, all fixed.

The largest was the `linear=true` claim, wrong in fourteen places. The docs said WaxOn and WaxOff never apply dynamic normalization. In fact `linear=true` is a *request* FFmpeg may refuse, and when it refuses, the filter falls back to dynamic normalization silently. The theory doc now explains when that happens and what it looks like.

**Known gap, shipped deliberately:** the app still gives no in-app signal when that fallback occurs. An affected file reads noticeably below its target LUFS in the stats panel with no explanation. Detection is tracked as [#11](https://github.com/sevmorris/WaxOnWaxOff/issues/11).

### Licenses and source code

The bundled `ffmpeg` and `ffprobe` are built with **no `--enable-gpl`**, **no `--enable-nonfree`**, and **no `--enable-version3`**. x264, x265 and libvidstab are not compiled in — **no GPL-licensed components remain**.

| Component | License |
|-----------|---------|
| FFmpeg 8.0 core | LGPL-2.1-or-later |
| LAME 3.100 (`libmp3lame`) | LGPL-2.0-or-later |
| `arnndn` filter | BSD-2-Clause |

The app itself remains GPL-3.0. It runs `ffmpeg`/`ffprobe` as separate executables, so the two licenses apply independently.

**Source (LGPL §6).** These binaries statically link LGPL code, so the corresponding source must be available. It is, at the exact pinned versions:

- **FFmpeg 8.0** — https://ffmpeg.org/releases/ffmpeg-8.0.tar.xz ([PGP signature](https://ffmpeg.org/releases/ffmpeg-8.0.tar.xz.asc))
- **LAME 3.100** — https://downloads.sourceforge.net/project/lame/lame/3.100/lame-3.100.tar.gz

The exact configure line, compiler flags, and SHA-256 pins are in [`scripts/build-ffmpeg.sh`](https://github.com/sevmorris/WaxOnWaxOff/blob/main/scripts/build-ffmpeg.sh). Full detail in [`Vendor/README.md`](https://github.com/sevmorris/WaxOnWaxOff/blob/main/Vendor/README.md). If you need the source by another means, open an issue with subject **source request**.

*Requires macOS 14.0 or later on Apple Silicon.*
