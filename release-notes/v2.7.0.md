### You can add files without dragging them

File ▸ **Add Files or Folder…**, or ⌘O. Until now dragging was the only way in — no button, no menu item, and ⌘O did nothing at all, which meant a keyboard-only user could not load anything.

The panel takes files or a folder. A folder chosen here is scanned the same way a folder dropped on the window is, because both go through the same code.

### The file list stays put while a batch is running

Remove and Clear were already disabled during delivery, but that only covered the toolbar. Swipe-to-delete and the Delete key were not, in either mode, so pressing Delete mid-batch removed rows the delivery was still writing to. All four routes are closed now.

Reordering is still allowed. It removes nothing, and the batch tracks its files by identity rather than position.

### WaxOff says why a file failed

It was already being handed the reason and showed a fixed "see Console" line instead. The row now says what happened, as WaxOn always has. Four alerts also stopped directing you to a "Console tab" that does not exist — the console is a toggle at the top right of the waveform area.

### WaxOn explains when Stereo applies

Mono and Stereo sat side by side with nothing to say which one you want, so Stereo read as the better choice and a single-voice recording ended up in a two-channel file for no reason. Use Mono for one microphone; use Stereo when one file holds two. That was already the advice in the manual — it is now under the control that needs it.

The Left/Right control below it is called **Source Channel**, so the two are no longer one letter apart.
